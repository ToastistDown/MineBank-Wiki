# 👛 Portemonnaie

Das **Portemonnaie** dient in MineBank zur kompakten Aufbewahrung von Bargeld und einer persönlichen Bankkarte.

So müssen Geldscheine, Münzen und die Bankkarte nicht ständig einzeln im normalen Spielerinventar transportiert werden.

---

## 🖱️ Portemonnaie öffnen

Das Portemonnaie wird mit einem **Rechtsklick** geöffnet.

Anschließend kannst du auf den Inhalt des Portemonnaies zugreifen.

---

## 💶 Bargeld aufbewahren

Im Portemonnaie kann physisches MineBank-Bargeld aufbewahrt werden.

Dazu gehören die unterstützten Geldscheine und Münzen.

## 💳 Persönliche Bankkarte

Neben Bargeld kann das Portemonnaie auch eine **persönliche Bankkarte** aufbewahren.

Dadurch können Spieler ihre Karte zusammen mit ihrem Bargeld transportieren.

➡️ [Mehr über die Bankkarte](../konten/bankkarte.md)
