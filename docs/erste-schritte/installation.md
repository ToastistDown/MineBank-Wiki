# 📦 Installation

## Voraussetzungen

Für MineBank benötigst du:

- Minecraft 1.20.1
- Forge 47.4.10 oder neuer
- Java 17

## Installation

1. Lade MineBank herunter.
2. Öffne deinen Minecraft-Ordner.
3. Öffne den Ordner `mods`.
4. Lege die MineBank-JAR dort hinein.
5. Starte Minecraft neu.

## Server

Bei einem Multiplayer-Server muss MineBank sowohl auf dem Server als auch auf den Clients installiert sein.
