# 📦 Installation

Auf dieser Seite erfährst du, wie du **MineBank 1.0.3** auf deinem Minecraft-Client oder Server installierst.

## Voraussetzungen

Für MineBank benötigst du:

| Komponente | Version |
|---|---|
| Minecraft | **1.20.1** |
| Modloader | **Forge 47.4.10 oder neuer** |
| Java | **Java 17** |
| MineBank | **1.0.3** |

!!! warning "Forge erforderlich"
    MineBank 1.0.3 ist für **Minecraft Forge** entwickelt. Achte darauf, die passende Mod-Version für deine Minecraft-Version zu verwenden.

---

## 🖥️ Installation auf dem eigenen PC

### 1. Forge installieren

Installiere **Forge für Minecraft 1.20.1**.

Für MineBank wird mindestens **Forge 47.4.10** benötigt.

### 2. MineBank herunterladen

Du benötigst folgende Mod-Datei:

```text
MineBank-1.0.3-forge-1.20.1.jar
